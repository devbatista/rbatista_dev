Projetos em Destaque

CatalystOps

CatalystOps é uma plataforma de gerenciamento de operações desenvolvida com Ruby on Rails. Permite a organização e monitoramento de ordens de serviço, tarefas, equipes e projetos, facilitando a colaboração e a eficiência operacional. Com recursos como autenticação de usuários, controle de acesso, upload de arquivos e uma interface intuitiva, o CatalystOps é ideal para empresas que buscam otimizar suas operações diárias, contando ainda com uma base de conhecimento completa e documentação centralizada dos processos e procedimentos operacionais.

Ruby on Rails HTML/SCSS Javascript PostgreSQL Devise (sessões via cookie) Gerenciamento de acesso Active Storage Mercado Pago

PrescSign

Plataforma full stack para prescrição e atestado digital, construída com Ruby on Rails e Vue.js. O projeto contempla controle de acesso multi-tenant, fluxo seguro de emissão e versionamento de documentos, assinatura com validação de integridade, geração de PDF e trilha de auditoria. Também inclui processamento assíncrono com Sidekiq/Redis e APIs REST para integração entre os módulos.

Ruby on Rails Vue.js PostgreSQL Docker APIs REST Autenticação Projeto autoral
